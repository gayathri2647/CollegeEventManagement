# College Event Planning and Management

## About the Event
College Cultural Fest 2026 is an event organized by students to encourage creativity, teamwork, communication, and cultural activities.

## Event Objectives
- Encourage student participation.
- Develop leadership and teamwork.
- Promote cultural talents.
- Improve communication skills.

## Event Details
- Event Name: College Cultural Fest 2026
- Date: 15 December 2026
- Venue: College Auditorium
- Organized By: Student Organizing Committee

## Main Activities
1. Inauguration
2. Dance Competition
3. Singing Competition
4. Quiz Competition
5. Fashion Show
6. Prize Distribution
